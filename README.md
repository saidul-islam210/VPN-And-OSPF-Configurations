#Project Description

This project demonstrates VPN and OSPF (Open Shortest Path First) configuration using Cisco Packet Tracer.
The main objective is to establish secure communication between remote networks through VPN tunneling and implement dynamic routing using OSPF.


##Technologies Used

  Cisco Packet Tracer,
  Cisco Routers,
  OSPF Dynamic Routing,
  VPN Tunneling,
  Cisco IOS CLI
